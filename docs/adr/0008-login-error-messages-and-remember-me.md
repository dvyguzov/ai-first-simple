# 0008. Раздельные сообщения об ошибках входа и чекбокс «Запомнить меня»

Дата: 2026-10-03
Статус: принято

## Context

Форма показывала одно сообщение «Неверное имя пользователя или пароль»
на любой неуспех: и на неверные креды, и на пустой логин, и на пустой
пароль. Пользователь не мог понять, какое поле исправлять. Домашнее
задание требовало раздельные сообщения для пустого `username`, пустого
`password` и обоих пустых полей, плюс чекбокс «Запомнить меня».

Браузерная валидация не помогает: у полей нет атрибута `required`,
поэтому пустой ввод доходит до скрипта и попадал в ветку неверных
кредов.

## Decision

В `index.html` проверки идут в таком порядке: оба поля пусты → пустой
`username` → пустой `password` → совпадение кредов → неверные креды.
Первые три ветки ставят класс `error`, поэтому вход с пустыми полями
физически не может стать успешным. Тексты: «Введите имя пользователя
и пароль», «Введите имя пользователя», «Введите пароль».

Пустота проверяется строгим сравнением с пустой строкой, без обрезки
пробелов: ввод из одних пробелов считается непустым и уходит в ветку
неверных кредов.

Чекбокс `#remember-me` стоит в форме между паролем и кнопкой, подпись
«Запомнить меня» обёрнута в `label.checkbox-label`. Отдельно
переопределена ширина: общее правило `input { width: 100% }` растянуло
бы чекбокс на всю форму. Логики входа чекбокс не меняет.

## Consequences

Сообщения стали частью контракта: автотесты проверяют их дословно, и
правка формулировки уронит тесты. Это осознанно — сообщение это то,
что читает пользователь.

Локаторы `#username`, `#password`, `button[type=submit]`, `#message`
не сломаны, ранее написанные тесты остаются валидными.

Чекбокс реализован как контрол формы без сохранения состояния между
перезагрузками: функции «запомнить логин» в `localStorage` нет, её
можно добавить отдельным решением.
