# Запуск тестов

## Прогон

```bash
./gradlew test --rerun-tasks
```

Gradle Wrapper лежит в git — установленный Gradle не нужен.
`--rerun-tasks` обязателен: без него повторный запуск помечает
задачу `up-to-date` и не выполняет ни одного теста — `BUILD
SUCCESSFUL` за 0.5 с не означает, что тесты прошли.
Тест открывает страницу с GitHub Pages — локальные правки
`index.html` в прогон не попадут, пока не опубликованы в форке.

## Где результаты

- Сырые результаты Allure (xml + вложения): `build/allure-results/`.
- Локальный отчёт: `allure serve build/allure-results`
  (нужен установленный Allure CLI).
- В CI отчёт — артефакт `allure-report` в прогоне Actions.

## Если тест упал

1. Прочитай stacktrace в выводе `./gradlew test` — там причина
   и локатор, который не нашёлся.
2. Скриншот на момент падения прикреплён к результатам, но `build/`
   в `.gitignore` — файлы оттуда агенту не читаются. Открой отчёт:
   `allure serve build/allure-results` → упавший шаг → скриншот.
3. Сверь локатор и ожидаемый текст с `index.html` — форма могла
   измениться (помни: бежит опубликованная на Pages версия).
4. Не меняй продукт молча: если сломан `index.html`, сначала уточни,
   это баг продукта или теста.
